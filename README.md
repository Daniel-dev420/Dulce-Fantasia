## 🍰 Sobre el proyecto

**Dulce Fantasía** es una tienda virtual ficticia de repostería creada como proyecto de desarrollo web.

El proyecto combina una interfaz atractiva con un sistema funcional para gestionar productos, usuarios, carrito de compras y mensajes de contacto.

- 👤 Registro de usuarios

- 👑 Sistema de roles y administrador
- 💌 Formulario de contacto
- 🗄️ Base de datos MySQL
- 📱 Diseño responsive
- 🐳 Docker
- ☁️ Despliegue en Render
