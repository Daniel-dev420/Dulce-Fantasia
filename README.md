# 🍰 Dulce Fantasía

### Una experiencia dulce, moderna y completamente digital.

Dulce Fantasía es una **tienda virtual ficticia de repostería**, desarrollada como proyecto de aprendizaje y demostración de desarrollo web.

El proyecto combina una interfaz atractiva con un sistema funcional de productos, usuarios, carrito de compras y almacenamiento de información mediante una base de datos.

---

## ✨ Características

### 🧁 Productos
- Catálogo dinámico de productos
- Imágenes y precios almacenados en la base de datos
- Información organizada por productos

### 🛒 Compras
- Carrito de compras
- Agregar productos
- Cálculo del total
- Proceso de compra

### 👤 Usuarios
- Registro de usuarios
- Inicio de sesión
- Roles de usuario
- Cuenta de administrador

### 💌 Contacto
- Formulario de contacto
- Guardado de mensajes en la base de datos
- Confirmación de envío sin abandonar la página

### 📱 Interfaz
- Diseño responsive
- Navegación adaptada a diferentes dispositivos
- Interfaz enfocada en una experiencia sencilla y agradable

---

## 🛠️ Tecnologías

`PHP` · `MySQL` · `HTML5` · `CSS3` · `JavaScript` · `Docker` · `Render` · `Aiven`

---

## ☁️ Despliegue

El proyecto utiliza **Docker** para la ejecución del servidor y **Render** para el despliegue de la aplicación.

La información se almacena en una base de datos **MySQL alojada en Aiven**.
